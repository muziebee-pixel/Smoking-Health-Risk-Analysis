# Smoking-Health-Risk-Analysis
the project focuses on analyzing smoking-related health data and transforming the dataset into an interactive dashboard that highlights important patterns, trends, and health risk indicators.
Smoking Health Risk Analysis is an end-to-end healthcare data analytics project developed using Microsoft Power BI.

The dashboard was designed as a portfolio project for demonstrating practical skills in data cleaning, data analysis, DAX, data visualization, and dashboard development.

## 🎯 Project Objectives
Analyze smoking patterns across different demographic groups
Identify key health risk indicators
Explore trends and relationships within the dataset
Create meaningful KPIs for quick analysis
Build an interactive and user-friendly Power BI dashboard
Present complex health data in a clear and understandable format
🛠️ Tools & Skills
Power BI
Power Query
DAX
Data Cleaning & Transformation
Data Visualization
Data Analysis
KPI Development
Interactive Dashboard Design
Data Storytelling
📈 Dashboard Highlights

The dashboard provides an interactive view of:

Smoking-related patterns
Demographic distributions
Health risk indicators
Key performance/health metrics
Trends and comparisons across categories

Users can interact with the dashboard using filters and visualizations to explore different aspects of the dataset.

## 💡 Key Learning

This project strengthened my ability to take a dataset from raw data to a finished analytical product by following an end-to-end workflow:

Data → Cleaning → Transformation → Analysis → DAX → Visualization → Insights
